# Evidence Noir — 측정 규칙 (렌더러 `scripts/dark_dossier.py` 가 그대로 지킨다)

> 기본 게시 형식은 다크사이콜로지 포맷(`scripts/dark_thread.py`). 이 문서의 규칙은 증거 파일형(`dark_dossier.py`, 대안 표지)과 모든 렌더의 자동 검사에 적용된다.

철학은 `design/PHILOSOPHY.md`. 여기는 숫자다. 규칙을 바꾸면 코드와 `scripts/dark_design_qa.py` 를 같이 바꾼다.
AI 에게 레이아웃을 맡기지 않는다 — 모든 위치·크기는 이 표에서 나온다(Canva AI 초안은 참고용, 게시 금지).

## 글자
| 역할 | 글꼴 | 크기/자간 |
|---|---|---|
| 주장(표지 훅) | Noto Serif KR 900 | 92 시작 → 상자에 맞을 때까지 4씩 줄임(최소 60) |
| 본문 | Noto Serif KR 700 | 60~64 |
| 기념비 숫자 | Gloock (+Noto Serif KR) | 300 시작 → 폭 936 에 맞춤(최소 140) |
| 표기(사건 번호·장·출처) | IBM Plex Mono | 18~20, 자간 4 |
| 목록 번호(외곽선) | Gloock | 360, 1px 외곽선만 |
중간 크기(34~52 사이 제목)는 쓰지 않는다 — 크거나 작거나.

## 장 종류
- **표지**: 오른쪽 위 증거 사진 창(468×600, 망점·흑백·1px 틀, «EXHIBIT A — FIG. 1») · 사진 모서리에 걸친 작은 붉은 도장 · 아래 전폭 주장 · 주장 길이에서 잰 가림 막대 3개.
- **수치**: 기념비 숫자 → 12칸 눈금자(퍼센트면 그 위치에 붉은 표식) → 설명 → 하단 각주 «[1] 출처».
- **목록**: 외곽선 번호(배경 쪽) → 붉은 표기 제목 → 본문.
- **문장**: 본문 한 덩어리 + 보조 한 줄.
- **끝**: 선언 → 저장 표시 → «END OF FILE — CASE N°».

## 자동 검사 (`dark_design_qa.py`, 렌더 직후)
1. 글자 요소가 여백 상자 밖으로 나가면 실패
2. 글자 요소끼리 겹치면 실패(장식 제외)
3. 글자 크기 16px 미만 실패
4. 붉은 글자 요소 3개 이상이면 실패(판정은 드물게)
실패한 편은 키트에 «디자인 검사 실패» 로 표시되고 게시 추천에서 빠진다.
