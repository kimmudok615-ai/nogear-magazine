## 2. 터지는 뼈대 5개
1. **극단 조건 / 금지** — «목에 칼이 들어와도», «절대», «하면 안 되는». 멈춤 → 스와이프.
2. **숫자 목록** — 5·7 이 가장 많다. 끝이 보이니 끝까지 본다(체류) → 다시 보려고 저장.
3. **정체성 거울** — «○○한 사람 특징». 읽는 사람이 자기를 대보고 친구를 태그한다(공유).
4. **순위·마지막 반전** — «1위는 충격», «마지막이 제일 무섭다». 마지막 장까지 체류.
5. **금지된 지식의 약속** — 바이오·표지에서 «아무도 안 알려주는». 팔로우 이유가 된다.

형식 공통점: 검은 배경 · 흰 글씨 · 한 장 한 생각 · 8초 정지 릴스 · 잔잔하거나 어두운 음악 ·
